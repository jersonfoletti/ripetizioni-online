# LinguaMentor — Ripetizioni online

Sito vetrina multilingua realizzato con:
- HTML5
- CSS3
- JavaScript vanilla
- Google Fonts

## Funzioni incluse

- Design responsive desktop/tablet/mobile
- Selettore lingua: Italiano, Deutsch, English, Español
- Lingua salvata nel `localStorage` del browser
- Sezione presentazione tutor con spazio foto
- 4 lingue/servizi
- Sezione "Come funziona"
- Prima lezione conoscitiva gratuita
- Form contatti che apre il programma email predefinito
- Animazioni leggere allo scroll
- Menu mobile

## Personalizzazione

Prima di pubblicare il sito, sostituisci:
1. `[Nome]` con il nome reale della persona.
2. `ciao@linguamentor.example` con l'indirizzo email reale.
3. Il riquadro "La tua foto" con una foto reale.
4. Eventuali testi, qualifiche, prezzi e disponibilità.
5. Nome/logo "LinguaMentor" se vuoi un altro brand.

## Inserire la foto

Il riquadro attuale è volutamente un placeholder. Puoi sostituirlo in `index.html` con, ad esempio:

<img src="images/tutor.jpg" alt="Foto di [Nome]">

e aggiungere `images/tutor.jpg`.

## Pubblicazione

Il sito è statico: puoi pubblicarlo su GitHub Pages, Netlify, Vercel, un normale hosting web o qualsiasi server che serva file HTML.

Nota: il form non usa un backend. Genera un link `mailto:` e apre il programma email dell'utente. Per un modulo realmente gestito dal sito sarà necessario aggiungere un servizio/backend per la gestione dei messaggi.
